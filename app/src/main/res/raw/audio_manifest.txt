Pashmak Game — audio drop-in list
=================================
ONLY THE THREE bgm_* FILES IN SECTION 1 ARE NEEDED.

Everything else on this list is spoken by the device itself. Pashmak reads
his lines aloud with the Android text-to-speech engine in a voice pitched
up and slowed a little so it suits a small woolly creature, so the app
talks with no recordings at all.

The one catch is Persian: most phones ship Google TTS, which has no Persian
voice, and then Pashmak goes quiet while the words still appear in his
bubble. Settings says so in plain words and names the free engines that do
speak Persian, so a parent can fix it in a minute. Nothing in the app is
blocked either way.

Every name below is an OVERRIDE. Drop a file in and that one line is played
from the recording instead of being spoken — one line, a whole screen or the
entire app, in any mix. This is how a real narrator can be added later
without touching the code.

Put the files in app/src/main/res/raw/ using exactly these names. Use .mp3
or .ogg, mono, 44.1 kHz. File names must be lowercase with letters, digits
and underscores only — aapt rejects anything else. Do not write the
extension; the app looks the file up by name, so welcome.mp3 and
welcome.ogg both work.


1. BACKGROUND MUSIC  (looping, instrumental, no singing)
--------------------------------------------------------
These are the three files to drop in for background music:

  bgm_menu               Splash, home, the mission list, the games menu,
                         the gallery and settings.
  bgm_play               Every mini-game and the whole live-drawing flow.
  bgm_story              The story screen — softer than the games loop.

  Make each one loop seamlessly; the app loops the file end-to-start with no
  gap. 60-120 seconds is plenty. The music ducks to a whisper automatically
  whenever Pashmak speaks and comes back up afterwards.

  If no file is present the app synthesises a soft wordless loop instead, so
  music plays either way. The bedtime screen plays no background music at
  all — the lullaby is the sound there.

3. SCREEN HINTS  (spoken once when a screen opens)
--------------------------------------------------
  help_default           خوب به این مرحله نگاه کن؛ فکر می‌کنی کدوم رو انتخاب کنیم؟
  help_paint             یه رنگ بردار و روی قسمت درست بزن. من راهنماییت می‌کنم!
  help_trace             انگشتت رو بذار روی حرف و آرام‌آرام دنبالش بکش.
  help_mission           بریم سراغ …! اول … رو روی کاغذ بکش.

  help_mission is shown with the mission and item names filled in. Record the
  sentence without them — for example: «بریم سراغ ماموریت! اول این رو روی
  کاغذ بکش.» The written line on screen still names them.

8. BUBBLES AND FREE DRAWING
---------------------------
  Bubble pop runs in rounds, each with its own rule — one named letter, one
  named digit, every letter, or every digit. The rule itself is read out from
  the strings below with the glyph filled in, so it cannot be recorded as one
  clip; bubble_round is the line between rounds.

  bubble_pop             ترکوندیش! ادامه بده.
  bubble_goal            حرف «…» رو بترکون!
  bubble_wrong           اون نبود قندعسلم. …
  bubble_round           آفرین! این دور رو بردی. بریم دور بعد.
  draw_empty             اول یه چیزی بکش تا ذخیره کنم.
