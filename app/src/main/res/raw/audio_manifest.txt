Pashmak Game — audio drop-in list
=================================
Put the recordings in this folder (app/src/main/res/raw/) using exactly these
file names. Any missing file is skipped silently; the game stays playable.

Mascot voice (mp3 or ogg, mono, 44.1 kHz):
  welcome        سلام قندعسلم! من پشمکم، دوست جدیدت! آماده‌ای باهم کلی بازی کنیم؟
  win1           هورااا! آفرین به قهرمان باهوشم! زدی تو هدف!
  win2           ایول بهت! دیدی چقدر زرنگی؟ بزن قدش!
  win3           ماشالله! این مرحله رو مثل آب خوردن بردی!
  try_again1     فدای سرت مهربونم! غصه نداره، یه بار دیگه دقت کن حتماً می‌تونی!
  try_again2     عیبی نداره کوچولو، حتی قهرمان‌ها هم تمرین می‌کنن! بیا باهم دوباره.
  giggle         قلقلکم نده شیطون بلا! ههههه
  poke           جونم قندعسل؟ منتظرتم‌ها، بیا بریم مرحله بعد!

Sound effects (short, under 1 second):
  sfx_pop, sfx_flip, sfx_match, sfx_star, sfx_shutter,
  sfx_wrong, sfx_brush, sfx_tap, sfx_whoosh, sfx_fanfare

Background music (looping):
  bgm_menu, bgm_play

Letter and digit pronunciation for the tracing game, named by code point:
  letter_627 (ا), letter_628 (ب), letter_67e (پ) …  — one per Persian letter
  digit_0 … digit_9

Lullabies for the bedtime screen (full songs, looped by the player, any length):
  lullaby_lay_lay        لای‌لای گل پونه
  lullaby_mahe_man       ماه من بخواب
  lullaby_gonjeshk       گنجشک لالایی
  lullaby_setare         ستاره‌ها بیدارن
  lullaby_abr_narm       ابر نرم
  lullaby_baran          صدای بارون
  lullaby_ahoo           آهوی کوچولو
  lullaby_darya          دریای خواب
  lullaby_pashmak        لالایی پشمک
  lullaby_shab_bekheir   شب به‌خیر ماه

  The list itself lives in data/catalog/LullabyCatalog.java — the titles, the
  verse shown under each one and the running time printed before the file
  arrives. Change them there if you record different songs. A lullaby whose
  file is missing is skipped, and Pashmak says so once rather than repeatedly.

File names must be lowercase with underscores only; aapt rejects anything else.
