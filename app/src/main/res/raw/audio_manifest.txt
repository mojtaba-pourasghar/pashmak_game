Pashmak Game — audio drop-in list
=================================
Put the recordings in app/src/main/res/raw/ using exactly these file names.
Any missing file is skipped silently; the game stays playable and the words
still appear in the speech bubble. Use .mp3 or .ogg, mono, 44.1 kHz.

File names must be lowercase with letters, digits and underscores only —
aapt rejects anything else. Do not write the extension in this list; the
app looks the file up by name, so welcome.mp3 and welcome.ogg both work.

Every line Pashmak speaks in the app is listed below with the exact file it
looks for. Nothing speaks without a name: MascotController.say() requires a
clip, so this list is complete.


1. BACKGROUND MUSIC  (looping, instrumental, no singing)
--------------------------------------------------------
These are the three files to drop in for background music:

  bgm_menu               Splash, home, the mission list, the games menu,
                         the gallery and settings.
  bgm_play               Every mini-game and the whole live-drawing flow.
  bgm_story              The story screen — softer than the games loop.

  Make each one loop seamlessly; the app loops the file end-to-start with no
  gap. 60-120 seconds is plenty. The music ducks to a whisper automatically
  whenever Pashmak speaks and comes back up afterwards.

  If no file is present the app synthesises a soft wordless loop instead, so
  music plays either way. The bedtime screen plays no background music at
  all — the lullaby is the sound there.

3. SCREEN HINTS  (spoken once when a screen opens)
--------------------------------------------------
  help_default           خوب به این مرحله نگاه کن؛ فکر می‌کنی کدوم رو انتخاب کنیم؟
  help_paint             یه رنگ بردار و روی قسمت درست بزن. من راهنماییت می‌کنم!
  help_trace             انگشتت رو بذار روی حرف و آرام‌آرام دنبالش بکش.
  help_mission           بریم سراغ …! اول … رو روی کاغذ بکش.

  help_mission is shown with the mission and item names filled in. Record the
  sentence without them — for example: «بریم سراغ ماموریت! اول این رو روی
  کاغذ بکش.» The written line on screen still names them.

  mission_done           مجموعه کامل شد! چه هنرمندی هستی تو!

  mission_start and item_arrived also carry a name on screen. Record them
  generically, e.g. «بریم سراغ ماموریت بعدی!» and «وااای! نقاشیت زنده شد و
  اومد تو صحنه!»

12. SOUND EFFECTS  (short, under a second)
------------------------------------------
  sfx_pop       a bubble bursting
  sfx_flip      a memory card turning over
  sfx_match     a correct answer
  sfx_star      a star being awarded
  sfx_shutter   the camera taking a photo
  sfx_wrong     a gentle "not that one" — never harsh
  sfx_brush     a pencil stroke on paper
  sfx_tap       any button
  sfx_whoosh    a screen or an item moving
  sfx_fanfare   a mission or a story finishing
